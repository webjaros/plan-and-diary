# To the Top

## Description
This game is much inspired by GTA 2.

## Setting
New-york-like megapolis.
Modern days.

## Features
- Police
- Open World
- Missions
- Wanted levels
- Car theft and driving
- Weapons
- Shop
- Massive multiplayer
- Day-night system
- Reputation system
- Crafting and upgrading weapons
- Inventory management
- Saving and loading
- Destructible environments
- Weather system: vision
- Weather system: driving
- Gangs
- Racing
- Gambling
- Police bribes
- Stealth

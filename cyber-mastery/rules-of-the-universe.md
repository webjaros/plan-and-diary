# Rules of the Universe

## Description
All my games will be in the same Universe. Although, the genre and the setting may differ very much, there will be things that are common for all the games.

## The Rules
- Skills and stats are incremented automaticly by using the skills. Like in Ultima Online.
- The character can travel between the games.
- Unlike UO, the skills and stats will degrade very slowly if not used.
- Not all skills are usable in every game.## Законы Вселенной
- mobile-first
- 2/2.5d
- Have idle and offline mechanics
- NPCs have memory about every player they interact with
- The world is affected by players
